# Godrej Nest · Navratri community ledger

A responsive React and Vite dashboard for the Godrej Nest Navratri 2026 community funds summary. It presents aggregate contributions, a searchable, scrollable list of 93 named contributors, recorded stall-fee receipts, outgoing event payments, and a date-based contribution trend. An explicitly anonymous receipt remains anonymous; flat numbers and individual contribution amounts are not displayed in the donor list.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The Vercel project configuration is in `vercel.json`.
