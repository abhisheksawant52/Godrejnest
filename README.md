# Godrej Nest · Navratri community ledger

A responsive React and Vite dashboard for the Godrej Nest Navratri 2026 community funds summary. It presents aggregate contributions, recorded stall-fee receipts, outgoing event payments, and a date-based contribution trend. Resident names, flat numbers, and donor remarks are intentionally not included in the site.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The Vercel project configuration is in `vercel.json`.
